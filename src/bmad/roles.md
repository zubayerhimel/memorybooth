# Roles and Responsibilities

## Product Owner
- Defines scope, priorities, and acceptance criteria
- Owns `prd.md` and roadmap updates

## UX/UI Designer
- Defines interaction flows and visual design
- Ensures accessibility and mobile usability

## Frontend Engineer
- Implements features in React/TypeScript
- Maintains hooks, components, and Canvas logic
- Owns `architecture.md` and `developer.md`

## QA Owner
- Defines test plan and manual QA checklist
- Coordinates cross-browser validation
- Owns `qa.md`

## Release/DevOps
- Ensures build and deployment pipelines
- Confirms HTTPS and hosting requirements

## Documentation Owner
- Keeps `bmad` docs current with the app
- Coordinates updates across roles
